Senior Python Developer

• Experience with message queuing systems (RabbitMQ, Kafka)
• Strong understanding of software design patterns and clean architecture

Preferred Qualifications:
• Experience with Apache Kafka or similar event streaming platforms
• Kubernetes administration and Helm chart development
• Experience leading a team of 3+ developers
• Microservices architecture experience
• Cloud platform experience (AWS/GCP)
• CI/CD pipeline implementation

Responsibilities:
• Design and build scalable backend services and APIs
• Lead code reviews and establish coding standards
• Mentor junior and mid-level developers
• Participate in architecture decisions and system design
• Ensure high availability and performance of production systems
